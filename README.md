# NCIGT website mockup

Draft mockup of a redesigned NCIGT website, for internal review only. Not the official NCIGT website. Bracketed items and grey circles are placeholders.

Live: https://nobyhata.github.io/ncigt-mockup/

- `index.html`, `industry.html`: the published pages
- `ncigt-logo.png`: NCIGT logo
- `design/`: design source files (desktop, phone and industry layouts) and `render.py`, which turns them into the static pages
